# infrastructure/krx

KRX(한국거래소) Open API 어댑터 모듈.

베이스 URL: `https://data-dbg.krx.co.kr/svc/apis`  
인증: 요청 헤더 `AUTH_KEY: {키값}`

> **사용 범위**: 이 어댑터는 **종목 목록 조회**에만 사용된다. 주가 데이터는 KIS(infrastructure/kis) 어댑터가 담당한다.

---

## 엔드포인트

| 용도 | KOSPI | KOSDAQ | KONEX |
|------|-------|--------|-------|
| 종목 목록 | `/sto/stk_isu_base_info` | `/sto/ksq_isu_base_info` | `/sto/knx_isu_base_info` |

공통 파라미터: `basDd=yyyyMMdd` (기준일)

---

## API 응답 정책 (실측)

### 종목 조회

| 조회 날짜 | 응답 |
|----------|------|
| 과거 영업일 | 데이터 반환 |
| 과거 주말·공휴일 | **데이터 반환** (직전 영업일 종목 목록 그대로 반환) |
| 당일 (미확정) | 빈 배열 `{"OutBlock_1":[]}` |

### 요약

- 날짜를 기준으로 "그 날 기준의 상장 종목 목록"을 반환하며, 비영업일에는 직전 영업일 목록을 그대로 돌려준다.
- **당일 날짜는 빈 배열을 반환한다.**

---

## T+1 데이터 제공 정책

D일 데이터는 **D+1일 약 08:00 KST 이후**에 제공된다.

```
D일 거래 마감 → D+1 08:00~ KRX 업로드 → 조회 가능
```

- 연휴 직후에는 연휴 전 마지막 영업일 데이터가 연휴 종료 다음 날 08:00에 제공된다.
- StockSyncJob(08:05 KST)은 **당일 종목 스냅샷**을 받아 최신 상태로 upsert한다(최근 거래일 목록이 곧 현재 상장 종목 전체). 과거 누락분은 백필 API로 보정한다.
